# Расписание КубГАУ

Многостраничный сайт с расписанием занятий для группы направления «Прикладная информатика» Кубанского ГАУ на две учебные недели.

**Демо:** [ссылка на GitHub Pages]

## Возможности
- Главная страница с выбором недели
- Расписание на первую и вторую неделю по дням (понедельник - пятница)
- Для каждой пары: время, дисциплина, преподаватель, аудитория, тип занятия (лекция, семинар, практика)
- Навигация между неделями и возврат на главную

## Страницы
| Страница | Назначение |
|---|---|
| `index.html` | Главная: выбор недели |
| `first_week.html` | Расписание первой недели |
| `second_week.html` | Расписание второй недели |

## Технологии
- HTML5 (семантическая вёрстка, таблицы)
- CSS3
- SVG (логотип в шапке)
- Публикация: GitHub Pages

## Запуск
Открыть `index.html` в браузере. Интернет не нужен.
